## Reporting a Vulnerability

If you discover a security vulnerability in AlertTime XSS Scanner, please report it responsibly:

### Contact Information

**Author:** Orkhan Khalafi  
**LinkedIn:** https://www.linkedin.com/in/orkhankhalafi/

### Reporting Process

1. **Do NOT** create a public GitHub issue for security vulnerabilities
2. Contact the author directly through LinkedIn
3. Provide detailed information about the vulnerability
4. Include steps to reproduce if applicable
5. Allow reasonable time for response and fix

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact assessment
- Suggested fix (if available)
- Your contact information

### Response Timeline

- **Initial Response:** Within 48 hours
- **Status Update:** Within 7 days
- **Fix Timeline:** Varies based on severity

### Responsible Disclosure

We follow responsible disclosure practices:

- We will acknowledge receipt of your report
- We will investigate and validate the issue
- We will develop and test a fix
- We will release the fix and credit you (if desired)
- We will coordinate public disclosure timing

### Security Best Practices

When using AlertTime XSS Scanner:

1. **Authorization Required**
   - Only scan systems you own or have explicit permission to test
   - Obtain written authorization before testing
   - Respect scope limitations

2. **Rate Limiting**
   - Use appropriate delays to avoid overwhelming targets
   - Monitor target system performance
   - Stop scanning if issues are detected

3. **Data Protection**
   - Do not store sensitive data from scans
   - Secure scan results appropriately
   - Follow data protection regulations

4. **Legal Compliance**
   - Comply with local laws and regulations
   - Follow ethical hacking guidelines
   - Respect terms of service
